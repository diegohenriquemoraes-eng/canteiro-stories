Calendário dos Stories

Os alertas de cada story do Canteiro, direto no calendário do iPhone. Uma vez só — depois ele se atualiza sozinho.

Assinar o calendário

Na tela que abrir: Assinar → Adicionar. Depois toque no calendário em Ajustes e confira que Remover Alarmes está desligado — é o que faz o aviso tocar.

Se o botão não abrir nada, faça pelos Ajustes:

  1. Ajustes → Apps → Calendário → Contas
  2. Adicionar conta → Outra → Adicionar assinatura de calendário
  3. Cole o endereço abaixo
https://diegohenriquemoraes-eng.github.io/canteiro-stories/canteiro-stories.ics
